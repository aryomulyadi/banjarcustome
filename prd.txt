Fase 2 — Auth admin + lacak pesanan (SELESAI)
- LOGIN KHUSUS ADMIN. Tidak ada register, tidak ada akun customer,
  tidak ada lupa password. Admin dibuat via seeder/tinker
  (admin@banjarcustom.test / password).
- Auth MANUAL, tanpa Laravel Breeze — breeze:install bersifat destruktif
  (menimpa routes/web.php, app.css, app.js, vite.config.js dan menurunkan
  Tailwind v4 ke v3); project ini bukan git repo sehingga tak bisa rollback.
- POST /login diberi throttle:6,1; pesan gagal selalu generik
  ("Email atau password salah.") untuk akun user-role maupun salah password.
- Middleware alias 'admin' = App\Http\Middleware\EnsureRoleIsAdmin (403).
- Login disembunyikan dari situs (tidak ada tombol Akun di header);
  admin membuka /login langsung. Setelah login: header menampilkan
  Dashboard + Keluar (khusus admin).
- Customer cek pesanan TANPA login: /cek-pesanan (ID order + nomor WA).
  Normalisasi nomor: buang non-digit, 62xxx -> 08xxx, buang nol depan.
  Akses ditautkan dari footer (Cek Status Pesanan) & halaman sukses pesanan.
- custom_orders.user_id dibiarkan nullable & TIDAK dipakai (riwayat
  berbasis akun dibatalkan). users.phone TIDAK ditambahkan.

Fase 3 — Dashboard admin (SELESAI)
- Prefix /admin + middleware [auth, admin], routes di routes/admin.php.
- Layout: resources/views/components/layouts/admin.blade.php
  (sidebar + topbar, token amber sama, sidebar mobile via Alpine).
- Modul:
  * Dashboard: stat (pending/production/completed/total/bulan ini/produk/
    kategori) + 5 pesanan terbaru.
  * Pesanan: tab filter status + pencarian nama/no WA + pagination;
    detail + update status (pending/production/completed) + unduh file
    desain (Storage::download) + tombol chat WA pelanggan.
  * Produk: CRUD + upload gambar (public/products, hapus file saat
    ganti/hapus) + palet warna baris-dinamis Alpine (simpan = hapus &
    insert ulang) + slug unik otomatis.
  * Kategori: CRUD; hapus DIBLOKIR bila masih ada produk (FK cascade).
  * Galeri: CRUD (public/galleries), pola sama produk.
- "Leads" = pesanan status pending pada modul Pesanan (tanpa modul
  terpisah).
